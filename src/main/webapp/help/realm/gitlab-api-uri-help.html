The base URL of your GitLab server, including the protocol.

Do not include /api/v4 in this field. The plugin appends /api/v4 automatically via the gitlab4j library.

Examples:
  • GitLab.com: https://gitlab.com
  • Self-hosted: https://gitlab.example.com
Common mistake: entering https://gitlab.example.com/api/v4 will result in a doubled API path (/api/v4/api/v4/user), causing a 404 error and an infinite OAuth redirect loop during login.
